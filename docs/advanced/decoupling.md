# 自建与独立节点按源解耦机制

在传统聚合订阅工具中，一旦节点有增删改动，往往必须重新下载完整配置文件并覆盖客户端。Subone 设计了按源订阅解耦方案。

---

## 为什么需要解耦？

- **痛点**：传统模式下，主配置文件中写死了大量实体节点。当外部机场节点变动或自建 VPS 更换 IP / 端口时，用户必须重新更新甚至重置整个客户端配置，这容易导致自定义规则和本地修改丢失。
- **解耦思路**：配置归配置，节点归节点。主配置文件中只保留策略组框架与分流逻辑，节点均以“订阅源（Remote Subscription）”形式引入。

---

## 工作原理

针对 **Sing-box 以外的客户端** (Loon、Mihomo (Clash)、Quantumult X、Egern)：

1. **外部机场订阅**：
   - 在生成的客户端主配置中，外部机场保持其原本的订阅链接引用；
2. **自建与独立节点组**：
   - Subone 自动将您在面板中录入的自建独立节点，转化为一个独立的按源订阅端点：
     ```text
     /s/:token/source/:sourceId
     ```
3. **主配置节点区留空**：
   - 主配置文件中的静态实体节点区留空；
   - 策略组直接绑定订阅源的 Tag 或名称。

### 带来的优势

::: tip 节点变动零侵入
当您的自建节点或机场节点发生变动时：
- 仅需在客户端上**单独刷新对应订阅源**；
- 完全不需要重新下载或覆盖主配置文件！
:::

> 注：Sing-box 客户端根据官方设计哲学，依旧保持全局内联 outbounds 逻辑以保证极致性能与稳定。
