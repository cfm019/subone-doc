# 控制台概览与多 Profile 管理

Subone 提供了简洁直观的 Web 可视化管理面板，支持从订阅源导入、策略组编排到客户端一键分发的一体化管理。

## 多 Profile 机制

在日常使用中，不同设备与场景通常需要差异化的分流策略与模版：
- **iPhone / iPad**：倾向于轻量、省电、使用 Loon 或 Quantumult X；
- **Mac / Windows 电脑**：倾向于 Clash / Mihomo，需要完整的开发分流规则；
- **家庭软路由 / 旁路由**：基于 Sing-box 透明网关，接管全屋流量与本地 DNS。

Subone 针对此场景设计了 **多 Profile 架构**：

1. **完全独立的 Token**：每个 Profile 拥有独立的访问 Token 和订阅 URL，互不干扰；
2. **差异化节点筛选**：每个 Profile 可以按需勾选不同的外部订阅源与自建节点组；
3. **独立的策略组与分流规则**：为每个 Profile 指定专属的策略组与规则集；
4. **定制化模版绑定**：每个 Profile 可指定适配目标设备的模版。

---

## 快速管理 Profile

进入控制台首页，您可以：
- **新建 Profile**：点击右上角“添加配置”，设置名称、描述并生成唯一访问 Token；
- **切换编辑**：点击左侧列表中的不同 Profile，可单独编辑其源、策略组与规则；
- **复制订阅链接**：直接点击“复制订阅”按钮，选择需要的客户端格式。
