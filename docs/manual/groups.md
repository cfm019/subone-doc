# 策略组管理与分类正则

策略组（Proxy Groups）是订阅配置中最烦重的工作之一。SubOne 支持可视化的策略组多级嵌套、正则筛选与国家/地区自动匹配。

![策略组列表与规则](/images/sub1-groups.png)

---

## 策略组类型

在创建或编辑策略组时，支持以下常见策略类型：

- **Select (手动选择)**：在客户端中由用户自由切换节点；
- **URL-Test (自动测速)**：定时向指定目标地址发起测速，自动选择延迟最低的可用节点；
- **Fallback (故障转移)**：始终优先使用首选节点，当首选节点不可用时平滑自动切换到下一个备用节点；
- **Load-Balance (负载均衡)**：在可用节点之间进行流量分担。

![编辑单个策略组](/images/sub1-group.png)

## 节点匹配方式

SubOne 允许灵活组合节点：
1. **指定节点 / 策略组**：直接挑选具体的节点，或者嵌套引用其他策略组（例如主选择组嵌套地区策略组）；
2. **正则匹配 (Regex)**：通过正则表达式（如 `(?i)香港|HK|Hong Kong`）动态匹配所有订阅源中符合条件的节点；
3. **按源筛选 (Source Tag)**：直接将某个订阅源或自建节点组的全部节点导入该组。

---

## 国家/地区识别规则与映射

系统内置了标准的国家和地区识别规则（`templates/country-rules.json`），能自动将带有香港、日本、新加坡、美国等关键词或 Emoji 国旗的节点映射到对应的地区策略组中，免去手工一条条筛选的繁琐工作。
